# Before and after

Before the dynamic engine, tailoring used a heuristic project score and emitted
an application packet for a separate drafting step. It did not distinguish exact
from adjacent matches or provide a PDF quality gate.

After the dynamic engine, a saved complete JD produces:

1. original and normalized requirements;
2. a requirement-to-evidence matrix with stable IDs;
3. dynamic skills ordered by supported relevance;
4. a new LaTeX/PDF/PNG version;
5. weighted coverage, traceability, rejected keywords, and machine validation.

The Epic demo is in `examples/epic_games_data_science_intern.json`.
