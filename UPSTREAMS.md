# Upstream resources

This project is an original integration scaffold that uses public interfaces/patterns rather than copying upstream projects wholesale.

- MadsLorentzen/ai-job-search — profile-first application workflow and factual grounding philosophy.
- SimplifyJobs/Summer2027-Internships — structured Summer 2027 internship listing feed.
- speedyapply/JobSpy — optional multi-board job discovery adapter.
- chintalaanvesh/jobpilot-ai-agent — useful reference for n8n/dashboard orchestration; not required in v0.
- AIHawk family — reference for autofill ideas only; not enabled by default because high-volume account automation can be brittle/risky.

Always review each upstream project's current license and terms before copying or vendoring code. This scaffold calls public data/interfaces and keeps upstream packages separate.
